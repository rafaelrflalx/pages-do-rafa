# Pages do Rafa — Landing Pages de Alta Conversão

Landing page autoral de alta conversão desenvolvida para Rafael Alexandre (Designer & Desenvolvedor Web).

## 🚀 Tecnologias
- HTML5 Semântico
- CSS3 (Design System com Variáveis CSS e Glassmorphism)
- JavaScript Vanilla (Interatividade & Acordeão do FAQ)
- Deploy automático via Vercel

## 📂 Estrutura do Projeto
- `index.html` — Estrutura unificada e otimizada da Landing Page
- `style.css` — Estilos visuais, animações e responsividade
- `script.js` — Lógica do menu fixo e expansão do FAQ
- `assets/` — Imagens do projeto
- `vercel.json` — Configuração para hospedagem na Vercel
